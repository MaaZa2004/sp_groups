# SP Groups — SP Designs and Construction

Premium architectural planning, luxury residential construction, and bespoke interior design studio showcase website based in Tiptur, Karnataka.

## 🏛️ Overview

**SP Designs and Construction** is a design and architectural showcase presenting architectural philosophy, tailored construction workflows, curated portfolios, and direct client consultation channels.

### Core Highlights
- **Architectural Philosophy**: Material-first craftsmanship, structural longevity, and contextual climate-responsive architecture.
- **Service Offerings**: Turnkey residential construction, bespoke interior design, architectural blueprints & MEP engineering, and structural renovation.
- **Interactive Experience**: Interactive portfolio gallery, smooth GSAP-driven scroll animations, tactile material palettes, and direct WhatsApp inquiry integration.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it using any local static file server (such as Vite, Live Server, or `npx serve .`).

## 🛠️ Tech Stack
- **HTML5 / CSS3 / JavaScript (ES Module Bundle)**
- **Styling**: Tailwind CSS & custom design tokens
- **Animations**: GSAP 3 (GreenSock Animation Platform) + ScrollTrigger
- **Typography**: Google Fonts (*Fraunces* & *Space Grotesk*)
- **Icons**: Lucide Icons
